1. Neue Ideen in die passende Liste mit vollständiger Vorlage eintragen.
2. Duplikatprüfung vor jedem Eintrag.
3. Kandidat ist keine Implementierungszusage.
4. Nur priorisierte Kandidaten werden als konkrete Arbeitspakete in `.ai/BACKLOG.md` übernommen.
5. Backlog-Curator-Agent: `.github/agents/backlog-curator.md`
