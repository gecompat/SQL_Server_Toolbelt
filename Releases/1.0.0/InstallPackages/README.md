# Vorgebaute CLR-Module für Toolbelt v1.0.0

Lade das [CLR-Installations-ZIP](SQL-Server-Toolbelt-1.0.0-CLR-Install.zip)
und die [SHA-256-Prüfsumme](SQL-Server-Toolbelt-1.0.0-CLR-Install.zip.sha256)
aus demselben Stand herunter. Die
[Schritt-für-Schritt-Anleitung](../CLR-INSTALL.md) erklärt Voraussetzungen,
Integritätskontrolle, Profilauswahl, SSMS-Installation und den ersten Test.

Das Paket enthält zwölf fertige Toolbelt-DLLs, ScriptDom, exakte Trustwerte,
SQL-Dateien mit eingebetteten Assemblybytes und den zugehörigen Quellcode.
Ein eigener Build ist für die Installation nicht erforderlich.

Dies ist ein unveröffentlichter Installationskandidat. Die
[Freigabematrix](../FREIGABEMATRIX.md) und die
[Releasegates](../RELEASE-GATES.md) begrenzen den Support; die Paketlieferung
ändert keine Modulversion und wertet keinen Prüfstatus auf.

Die enge Ignore-Ausnahme erlaubt nur diese Dokumentation und den benannten
ZIP-/Prüfsummensatz. Lose Buildartefakte und private Labjournale bleiben draußen.
