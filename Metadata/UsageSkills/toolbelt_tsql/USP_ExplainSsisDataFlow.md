# USP_ExplainSsisDataFlow

## Zweck und Einsatzfälle

Debug-SQL aus DTSX-XML, Paketdefaults und optionalen JSON-Startwerten. Standardmäßig paketbasierter Entwurf ohne Quellkatalogzugriff; CatalogMode=catalog wählt strengere Prüfung. Keine automatische Paket-/SQL-Ausführung.

Reviewentwurf: vorhandene Beschreibung mit der Implementierung abgleichen.

## Voraussetzungen

- Windows SQL Server 2019/2022/2025, separate UNSAFE-Assembly, exakter Parser 2.0.1/ScriptDom-Pin und Result Table 1.0.0. Aktuelle Liefer- und Prüfgrenzen gemäß CurrentInstallation.md; historische Nachweise bleiben getrennt.
- DTSX als Bytes übergeben. Für explain explizite Same-instance-Datenbank-/Connection-Allowlist und vorhandene vollständige Metadatensicht; keine Credentials im JSON. Nur values der vollständigen Bindings-Vorlage bearbeiten.
